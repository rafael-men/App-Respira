# Respira em Flutter

Código do app Respira. A Sprint 4 usa Flutter 3.50.0 e Firebase em Android, iOS e web. Consulte o [README principal](../README.md#teste-web-e-demonstração-do-sos) para executar no navegador ou no Android.

Para validar o app, execute em `respira_main`:

```powershell
flutter pub get --enforce-lockfile
flutter analyze --no-fatal-infos
flutter test
```
